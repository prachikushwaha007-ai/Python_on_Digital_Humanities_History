# Python_on_Digital_Humanities_History

This repository contains Python projects and Jupyter Notebooks demonstrating the application of Natural Language Processing (NLP) and regular expressions in Digital Humanities, specifically focusing on historical texts like Duarte Barbosa's work.

## Projects Included

### 1. NLTK Project
* **Notebook:** `_1_NLTK_Tokenizing_Duarte_Barbosa_Book_Introduction.ipynb`
* **Description:** Focuses on text preprocessing, sentence/word tokenization, and basic linguistic analysis of historical text using the NLTK library.

### 2. SpaCy Project
* **Notebook:** `SpaCy_on_Barbosa_Short_Text_File.ipynb`
* **Description:** Implements advanced NLP workflows using SpaCy, sentence segmentation, Named Entity Recognition (NER) to extract historical figures.

### 3. RegEx Project
* **Folder:** `RegEx_Project_Extract`
* **Description:** Uses Regular Expressions (RegEx) for pattern matching, structural text cleaning, and extracting specific sections or keywords from raw historical files.

## Tech Stack & Libraries
* **Python 3.x**
* **NLTK**
* **SpaCy**
* **Pandas**
* **Jupyter Notebook**
